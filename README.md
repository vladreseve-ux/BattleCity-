# Battle City (Танчики) — WPF .NET 10

Реализация классической аркадной игры **Battle City** на платформе WPF (.NET 10).

## Особенности и улучшения

* **Плавный геймплей (60 FPS):** Отрисовка переведена на `CompositionTarget.Rendering` с непрерывной интерполяцией движения танков и снарядов (`VisualX`, `VisualY`), устранены дискретные рывки между клетками сетки.
* **Анимация гусениц:** Вращение траков танка во время движения и плавная физика взрывов.
* **Сбалансированная скорость:** Выверенная комфортная скорость полёта снарядов и передвижения техники.
* **Условие победы:** Полноценная кампания из 3 уровней с нарастающей сложностью. При прохождении 3-го этапа засчитывается победа («ПОБЕДА!»).
* **Усиленные укрытия:** Прочность кирпичных стен увеличена до 3 HP с визуализацией стадий разрушения (целый кирпич -> сколы -> трещины -> взрыв).
* **Система сохранений:** Сохранение и загрузка прогресса в JSON (`save.json`).

## Управление

* **WASD** / **Стрелки** — передвижение танка
* **Пробел** — выстрел
* **P** — пауза
* **N** — новая игра

## Сборка и запуск

```bash
dotnet build
dotnet run --project BattleCity.Wpf.csproj
```

Запуск тестов:
```bash
dotnet test
```
